# Ejercicio Comparativo: Bubble Sort vs Insertion Sort

Este repositorio contiene la solución al Ejercicio 21 de la Unidad 2, el cual consiste en un ejercicio comparativo de rendimiento entre dos algoritmos de ordenamiento clásicos.

## Descripción del Ejercicio
El programa genera un arreglo base de 1000 elementos aleatorios y evalúa el rendimiento del **Bubble Sort (Optimizado)** y el **Insertion Sort** bajo tres escenarios distintos:
1. Arreglo Aleatorio.
2. Arreglo Casi Ordenado.
3. Arreglo Ordenado en Sentido Inverso.

Para cada prueba se registran tres métricas fundamentales: tiempo de ejecución en milisegundos, cantidad de comparaciones lógicas y cantidad de intercambios/desplazamientos de memoria.
